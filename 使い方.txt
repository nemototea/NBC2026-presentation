NBC本戦プレゼン「一杯の設計図」
============================================

■ 渡し方 / 開き方
  NBC_Presentation.html というファイル1つだけをコピーして渡してください。
  外部ファイル・インターネット接続・フォントのインストールは一切不要です。
  ダブルクリックすると既定のブラウザで開きます。
  （Chrome / Edge / Safari / Firefox すべてで動作します）

■ 発表前にやること
  1. ファイルを開く
  2. F キーを押して全画面にする   ← これだけ
  ※ 全画面にしないとブラウザのタブやアドレスバーが写り込みます。

■ 操作
  →  Space  ↓  PageDown  画面クリック ……… 次のページ
  ←  ↑  PageUp ………………………………… 前のページ
  F ………………… 全画面 ／ 解除
  N ………………… 発表者ノート（時間配分・言い方の注意）を表示／非表示
  T ………………… 経過タイマー表示／非表示    R … タイマーをリセット
  O ………………… スライド一覧（クリックでジャンプ）
  ? …………………  操作ヘルプ
  Esc ……………… 閉じる

  ※ プレゼンター用リモコン（PageUp / PageDown を送るタイプ）でも動きます。

■ 注意
  ・N キーのノートは画面に大きく出ます。プロジェクターに映したまま押さないでください。
  ・全21ページ。本編は 1〜15、16〜21 は質疑応答用（本編では飛ばす）。

■ アニメーションについて
  ・7ページだけ「→ を2回押す」構成です。
      1回目に入った時点   … 50℃・60秒 のバーが伸びる（青）
      → を1回押す        … 70℃・60秒 のバーが伸びる（赤）
      もう一度 → を押す  … 次のページへ
    ← を押すと1段戻ります。
  ・8ページはページを開いた時点で温度グラフが自動で描かれます。
    もう一度見せたい場合は ← → で戻ってくれば再生されます。

■ 表現の境界（設計ブック §10 の監査結果を反映済み）
  スライド上には次の断定を一切載せていません。
  ・「50℃なら旨味だけが出る」
  ・「川根本町と鹿児島を淹れ分けている」
  ・「90℃・10秒が科学的最適値」
  ・「30mLが科学的に導出された最適湯量」

■ 数値の出どころ（すべて坂本ら 2002／煎茶4g・120mL）
  7ページ  50℃・60秒 と 70℃・60秒 の1煎目。
           青と赤は「別々に淹れた2つの1煎目を並べたもの」であって、
           低温のあとに高温を重ねた結果ではありません。棒を積み上げず、
           同じゼロ基点から2本並べているのはそのためです。
           カフェインは60℃38.4%・70℃34.6%と単調に増えないため、
           誤解を避けてこのグラフからは外しています。
           ※想定質問（なぜ84℃でなく70℃か／EGCGも2.5倍では）への
             回答は N キーの発表者ノートに入れてあります。
  18ページ テアニン40.5%／EGCG6.9%＝約6倍。
           アミノ酸類全体では約5〜8倍（設計ブック §6）。
           ※設計ブック内でグルタミン酸の値が47.0%と52.4%で
             食い違っているため、両記述で一致するテアニンのみを使用。
  20ページ 90℃・1煎目60秒＋2煎目10秒の「累積」溶出割合。
           2煎目だけの値ではありません。
  いずれも拓朗（午）の実測値ではありません。
